## Overview

TENS is a transient shaper that independently amplifies or attenuates the attack transient and sustain body of a signal, with program-dependent detection and a parallel blend for transparent shaping.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Klanghelm TENS** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Attack Control** | Amplify or reduce transient onset without affecting the body |
| **Sustain Control** | Extend or shorten the signal body envelope independently |
| **Program Detection** | Automatic envelope detection adapts to signal content |
| **Parallel Blend** | Mix processed and dry signal for subtle transparent transient work |
